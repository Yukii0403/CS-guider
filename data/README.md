# data/ —— 预置演示数据

## 为什么需要这个目录

**评委第一次打开作品时，知识库是空的。**

如果什么都不预置，评委看到的是一个空壳——他得先自己编一个项目、贴一段代码、等半天，才能看到效果。而评委在每份作品上停留的时间可能只有几分钟。

所以预置数据不是"作弊"，而是**把产品最好的一面直接摆在他面前**。

## 预置的三样东西

| 文件 | 作用 |
|---|---|
| `seed-domains.json` | 领域树第一层（8–12 个节点）。这是追问收敛的骨架，必须手工写好 |
| `seed-knowledge.json` | 一个示例用户的知识库状态，用于展示能力画像与缺口分析 |
| `sample-project/` | 演示用的项目代码（MNIST 分类，脱敏后）。评委点一下就能看到"能力反推"的完整效果 |

## 使用方式

首次进入时应自动检测：知识库为空 → 提示"载入演示数据" → 一键灌入。

**同时要给评委留出"从零开始"的路径**——他可以清空演示数据，用自己的项目试。预置是降低门槛，不是替代体验。
